- 日期：2026-11-02
- 范围：EP01 正式产物（68 镜 prompt + 65 镜 segments + framing/ref_characters）+ 资产层（6 角色 / 5 场景 / 4 道具）+ 生产规则（prompts.py `_board_rules` 等）
- 方法：确定性量化脚本 `state/_full_audit.py`（七维度指标）+ 抽样原文走读（SH01/02/03/09/13/30/37/41/45/50-65）+ 质量门/gate/drama 三扇门复核
- 用户判据：不看字符数量，看 **重复 / 无效字符 / 关键信息能否准确完整表达剧情**

## 0. 一句话结论

**文本层整体健康**：无句级复制、无景别/运镜矛盾、叙事性词极少、场景锚点连贯；真实缺陷共 3 类——**① 拍摄调度词混入 prompt_en（13 镜，S5 对话段为主）② 空泛修饰词（5 处 vivid/serene）③ C3 女巫 / C5 婶婶的"瘦长脸老年女性"指代重叠（跨角色歧义风险）**。①②本轮已修规则并上质量门 warn；③建议资产层差异化 + P1 verbatim 重生成后验证。另有 2 处轻微含糊（SH45/SH62 "something"）。

## 1. 七维度甄别结论

### 1.1 合理性 —— 健康

| 指标 | 数值 | 判定 |
|---|---|---|
| 整镜 prompt 词数 | min 39 / max 89 / avg 57 | 适中，无堆砌 |
| 无 ref_characters 镜 | 0 | 全部镜都声明了在场角色 |
| 整镜无动作动词镜 | 3 → **真实 1**（SH35 定场全景） | SH35 属 establishing 豁免；SH37/46 为脚本词表漏检（jolting/bolting） |
| S1 镜命中场景 plate_prompt 名词 | 5~32 个/镜 | 场景基线信息扎实 |

抽样走读（SH01→SH02→SH03：龙卷风大全景→屋内抱狗转身→门口农夫喊话）动作因果、情绪递进连贯，prompt 均"主体+动作+材质+光线+情绪"可渲染。

### 1.2 重复 —— 句级干净，短语级属风格一致

| 指标 | 数值 | 判定 |
|---|---|---|
| 相邻镜 prompt 相似 >0.45 | **0 对** | 无句级复制粘贴 |
| segments 段间重复 | 质量门 0 block / 4 warn | P0 语义拆段后无退化 |
| 全片重复 bigram（≥3 次） | 83 种，TOP：grey light ×18、one hand ×17、small black ×14、black dog ×13、elderly woman ×10、hard noon ×9、dialogue elderly ×8… | **短语级复用 = 自包含提示词的合理基线**（每镜独立成句，须自带场景光线），非复制；但 grey light ×18 提示场景光线短语可收敛进 P0.5 配方句 |

关键澄清：重复集中在**光色短语**（grey light/hard noon/strobing grey）与**角色指代**（small black dog/elderly woman），是跨镜风格一致性的来源，不是无效字符。

### 1.3 冗余 —— 两处真实问题（本轮已修）

| 指标 | 数值 | 判定 |
|---|---|---|
| 空泛修饰词 | 5 处 / 5 镜（SH35/36/41/44 **vivid**、SH50 **serene**） | **真问题（轻微）**：不传递可渲染信息 → 质量门已加 `prompt.fluff` warn |
| **拍摄调度词混入 prompt_en** | **13 镜 / 21 处**（S5 对话段 "Medium dialogue shot: the elderly woman…" ×10、"reaction shot" ×1、"POV" ×2 含 SH41 "point-of-view shot"） | **本轮最大真实缺陷**：拍摄类型/视角术语是调度指令，应放 framing/coverage，污染画面描述且句首模板化（"dialogue elderly" bigram ×8 佐证）→ 规则已硬禁 + 质量门 `prompt.director_word` warn |
| 长度异常 | 无（39~89 词分布正常） | — |

澄清：SH05/SH10 "Close insert"、SH28/30/32 "Extreme close" 等**景别复合开头**是首帧画面信息，不算调度词（质量门已豁免）。

### 1.4 矛盾 —— 无（脚本误报已甄别）

| 指标 | 第一版脚本 | 甄别后 |
|---|---|---|
| prompt 景别词 vs framing.shot_size | 50 处 | **真实 0**：脚本 `sid, p = s["shot_id"], prompts[sid]` 元组解包求值顺序错误，`prompts[sid]` 用了上一轮 sid 导致 p 错位一镜（SH02 匹配到 SH01 的 "Extreme wide"）；修正后仅剩 SH05/SH10 "Close insert" 配 close_up（语义一致，判据过严） |
| prompt 运镜词 vs camera_move | 0 | 0，真实 |
| prompt 角色 vs ref_characters | 见 1.6 | 对话镜 ref 含不在画面的角色（SH60/64 的 C1），轻微，语义待约定 |

### 1.5 含糊 —— 极轻微

- 11 处中 **10 处 "around" 为空间介词合理用法**（"dust motes turning around"、"crowd arranged around"）
- **2 处 "something" 为真实轻微含糊**：SH45 "eyes locked on something distant"（看向何物不可定位，建议改 "gazing at the far horizon"）、SH62 "as if weighing something vast"（隐喻但动作可拍，可接受）
- 资产层 identity_prompt 无含糊（around/about 均为年龄正常表达）

### 1.6 叙事性 —— 极干净

- 全片仅 3 处：slowly ×2（SH13 "dust motes turning slowly"、SH30 "spinning slowly"——**动作修饰，可拍**）+ as if ×1（SH62）
- 无心理活动词（realizes/remembers/longing 等 0 命中）、无背景叙事句——prompt 全部是画面内容，符合"首帧画面"规则

### 1.7 连贯性 —— 良好，一处跨角色风险

| 指标 | 数值 | 判定 |
|---|---|---|
| 相邻镜空间/动作衔接（SH01-03、SH50-54 走读） | 连贯 | 情绪递进、方位可对上（女巫 frame left、人群 frame right） |
| 角色指代可辨识 | 21/68 镜词表未命中 → 甄别后**均为合理指代** | farmer / older woman / small black shape / white-robed woman / silver toe caps 均能锁定角色，符合旧规则（不写姓名、外貌指代）但**非 P1 要求的逐字锚点短语**——规则已落地，产物待重生成即达标 |
| 场景锚点 | S1 命中 plate_prompt 名词 5~32 个 | 场景连贯扎实 |

**真实风险——C3/C5 跨角色指代重叠**：
- C3 北方女巫 identity：*elderly woman ~70, tall thin, **long lean face**… 白袍银星*
- C5 爱姆婶婶 identity：*thin gaunt ~40, **long lean face**… 灰裙围裙*
- prompt 中婶婶常写 "an older woman"、女巫常写 "the elderly woman"，**仅差一个词且同为瘦长脸**；S2 地窖戏（婶婶）与 S5 对话戏（女巫）若渲染层只取首句主体，存在串人风险。**P1 verbatim 规则强制逐字锚点可缓解；建议资产层进一步差异化**（见 §3）。
