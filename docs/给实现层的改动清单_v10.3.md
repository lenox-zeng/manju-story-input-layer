## 1. 契约 v10.3 新增/变更（实现层必须适配）

### 1.1 旁白锚点契约（v10.3，gate 强制 block）
- 旁白**唯一权威**在 `storyboard.shots[].narration`（script 级 narration 必须留空，防 0.1s 漂移）。
- 每条旁白必须带锚点字段：`shot_id` / `at_sec` / `timing_sec` / `anchor_mode`（`within_shot` | `voiceover_span`）/ `allow_span_shots` / `allow_cross_scene` / `max_shift_sec`。
- gate 判定：`timing_sec ≥ ceil(汉字数/5)`；`at_sec` 必须落在锚镜 `[start, end)`；`within_shot` 不得越出锚镜；`voiceover_span` 不得超 `allow_span_shots` 且 `allow_cross_scene=false` 不跨场；旁白与台词/旁白重叠或空隙 <0.08s = block。
- 旁白不设置 `subjects[].speaking`，不触发口型，不进 audio。

### 1.2 摄影配方 CameraRecipe（P0.5）
- 每镜 prompt 结尾必须给出摄影配方两件套，对应契约字段（framing 层）：
  - **光**：`light_recipe` = 光源方向（screen-left/right/behind/top/rim）+ 质量（hard/soft/diffused）+ 色温冷暖（cool grey daylight / warm lamplight / dusk orange）；
  - **镜**：`lens_recipe` = 焦段 + 景深（50mm shallow / 35mm deep / 85mm compressed）；
  - `camera_recipe` 汇总机位形态（static/handheld/tripod/steadicam）。
- **不给光照 = 引擎默认平光**（画面"假/平"第一根因）。配方不得与美术圣经 style_keywords/do_dont 冲突，不得写成运镜词（运镜只在 `camera_move`）。
- 兼容：v10.4 语义兼容旧产物（无配方镜 warn 不 block）。

### 1.3 角色锚点 verbatim（P1）
- `story_assets.json` 的 Character 新增 `pose_library` / `expression_library`（可枚举姿态/表情库）；`identity_prompt` / `identity_anchor` 为身份锚点。
- 生成侧硬性：prompt/segments 里出现 bible 角色时，该角色的**可一眼识别锚点短语**（发型/疤/服饰色块/高帽等）必须**逐字复用**，不得改写（防止渲染层串脸）。
- 实现层：`identity_anchor` 短语是角色参考图/锁脸的关键词源；`ref_characters` 对应的定妆图必须存在。

### 1.4 ref_characters 语义（2026-11-02 自检定稿，commit 6191b95）
- `ref_characters` = 本镜**画面内实际出现**的角色清单（含局部/道具/肢体代指，如"靴子特写→C4"、"床底项圈→C2"；含全景中极小但物理在场者）。
- **不在画面的画外角色（有声音/被提及/纯对话对象）不入 ref_characters**，改用 `subjects[].offscreen=true`（§6.5 已有字段）。
- 层级约束：`ref_characters ⊆ subjects ⊆ 本场景 chars_on_screen`；每个 ref 角色在 prompt_en 必须有可辨识指代。
- 影响：实现层取角色参考图时只按 ref 取**画面内**角色，避免把画外人硬塞进画面；画外对话对象不参与参考图注入。

### 1.5 prompt_en 禁拍摄调度词（2026-11-02，commit 8d9410f）
- 生成侧硬性：`dialogue / reaction / insert / point-of-view / establishing / two-shot / over-the-shoulder / POV` 等**拍摄类型/调度词一律禁止进入 prompt_en**；景别/机位/视角由 `framing` / `coverage` 结构化字段表达。
- 旧产物曾出现 "Medium dialogue shot: ..." 等 13 镜调度词前缀（SH55-63/67 dialogue、SH65 reaction、SH17 POV、SH41 point-of-view），已由质量门 warn 检出（`prompt.director_word`）。
- 实现层：**不要**依赖 prompt 中的 "dialogue shot / POV / reaction" 等词做行为推断，一律读结构化字段（coverage、camera_move、subjects[].speaking）。

### 1.6 segments 语义拆段（P0，契约 §8 字段）
- 动作节拍数 >1 的镜**必须**输出 segments（1–3 段，一段一个主动作；段秒数和=整镜；段区间连续不重叠；段级 state_out → 下一段 state_in 承接；末段 `keyframe=true` + `frame_hint="last"`；单动作镜省略）。
- 每段 text 是**独立动作句**（start=动作起点 / mid=过程 / end=完成+结果承接），禁止复制整镜 prompt 开头、禁止同镜各段内容相同。
- 兜底（确定性）：LLM 未写 segments 时按动作数拆 2-3 段（`_fallback_segments`：n_actions≤1 → 不分段）。
- 实现层消费（LTX 阶段化）：`segments` 非空时每段经 LTXVAddGuide 注入（指南 §8.4 已有）；尾帧串联用末段 keyframe。

## 2. 质量门与验证（实现层可见的行为变化）

- `scripts/check_prompt_quality.py` 现有 9 项 warn + 2 项 block 判据：
  - block：`seg.dup`（Jaccard>0.60）、`seg.prompt_head_copy`（非首段以整镜 prompt 前 15 词为前缀）；
  - warn：`seg.no_verb`、`seg.too_short`（<4 词）、`seg.near_dup`（>0.40）、`seg.prompt_overlap`、`prompt.no_light_recipe`、`prompt.no_lens_recipe`、`prompt.no_camera_recipe`、**`prompt.director_word`（调度词）、`prompt.fluff`（空泛词 vivid/serene 等）**。
- 单集目标时长硬区间 **80-90s**（`--duration` 默认 90.0；180 已不允许）。
- gate（manju/gate.py）：台词语速 ≥ ceil(字数/5)；旁白锚点；at_sec 落锚镜；空隙 <0.08s 等 block 判定。
