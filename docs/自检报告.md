# 纯输入层包自检报告（v2.0）

日期：2026-10-27
包版本：manju-story-input-v2.0.0
验证环境：Windows 11 / Python 3.11.9 / pytest（本地虚拟环境）

> **纯净包说明**：本报告记录 v2.0 输入层工作区的离线自检。交付的纯净包已剔除
> `config.json`、全部小说样书、`state/` 中间产物与 `output/logs` 生成结果；
> 因此文中涉及工作区样书的命令需替换为你自己的 `input/<小说>.txt`。
> 纯净包另做了静态扫描与干净目录回归，见根目录 `PACKAGE_NOTES.md`。

## 范围

本包包含：

- L1 故事层（`manju/story/`）：解析、预处理清理、章节回退、情节原子、按戏剧单元分集、
  长篇压缩、两级大纲、连续性、质量门、编译器、LLM 流水线
- L2 v10.2 契约编译（`manju/story/compile.py`）
- 契约审计（`manju/gate.py` / `manju/drama.py`）
- 文本模型客户端（`manju/llm.py`）
- 独立入口（`manju/story_cli.py`）、人工审阅（`manju/story/review.py`）、Studio（`manju/studio.py`）
- v2.0 工具：离线验收、产物审计、通过率测量（`scripts/`）
- 叙事增强：结构化旁白/内心独白（`scene.narration`）与场间转场
  （`scene.transition_in`），并在编译、`gate`、`drama` 中贯通校验

不包含：ComfyUI 客户端、能力注册表、适配器、工作流、渲染编排、素材与运行记录。
这些属于下游实现层；输入层与下游之间的接口说明见 `docs/ComfyUI对接指南.md`，
字段语义以 `docs/漫剧文本输入契约_v10.2.md` 为唯一来源。交接只给“契约 + 平台指南 + 完整样例”
（纯净包不含生成结果，样例需单独提供），
不交付 `manju/schemas.py` / `gate.py` / `drama.py`。

## 复现

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\scripts\verify_offline.py
python scripts\pass_rate.py
```

`verify_offline.py` 会依次执行：语法编译 → 测试 → `--version` → `--doctor`；
若 `input/` 下有小说，再跑 `--dry-run`。全程不调用模型 API。

## 隔离与基线

- 纯净包独立目录，不共享 `config.json`、`state/`、`input/`、`output/`、`logs/`。
- `config.json` 不随包交付；首次使用从 `config.example.json` 复制，API Key 只放环境变量。
- 包内不含小说正文、样书、中间产物、生成结果与真实 Key。
- 版本与测试数见 `VERSION`、`CHANGELOG.md`。
